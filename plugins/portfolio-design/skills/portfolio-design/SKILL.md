# 화면 세 가지 만들고 하나 고르기

**하나를 잘 만드는 게 아니라, 푸는 방법이 다른 셋을 만들고 고르는** 스킬이다.
고른 이유와 포기한 것까지 남기는 것이 이 스킬의 결과물이다.

## 1단계 — 무엇을 만들지 받는다

바로 만들지 않는다. 아래를 묻고 `screen-brief.md` 로 정리한다.
학생이 문제 정의서를 갖고 있으면 붙여넣게 하고, 없으면 대화로 채운다.

```markdown
# 화면 요구 명세
## 이 화면에서 사용자가 끝내는 일
{무엇을 끝내려고 여기에 오는가}
## 사용자가 여기서 골라야 하는 것
{하나로 적는다. 두 개 이상이면 화면을 나눠야 한다는 신호}
## 반드시 보여야 하는 정보
1. 2. 3.
## 어디서 들어오고, 무엇이 되면 끝인가
## 화면 순서 (3~5단계)
1단계 {화면} → 여기서 고르는 것 → 다음으로 넘어가는 방법
2단계 …
```

**"골라야 하는 것"이 비면 진행하지 않는다.** 이게 없으면 예쁘지만 쓸모없는 화면이 나온다.

## 2단계 — 접근 축을 정한다

색이나 버튼 모양이 아니라 **사용자에게 시키는 일이 다른** 세 가지를 정한다. 예:

- 안 A — 다 보여 주고 사용자가 고르게 한다 (사용자가 통제)
- 안 B — 제일 나은 하나만 보여 준다 (고를 부담 최소)
- 안 C — 한 번에 하나씩 물어본다 (실수 최소)

학생과 축을 합의한 뒤 화면을 만든다. `design` 스킬이 있으면 그것을 호출하고, 없으면 화면 구성을 글과 그림으로 설명한다. 명세의 과업·결정·필수 정보를 그대로 반영한다.

## 3단계 — 저장한다

각 안의 화면을 그림 파일로 저장하게 안내한다.
```
options/A/01.png, 02.png …
options/B/…
options/C/…
options/notes.md   ← 각 안이 어떤 접근인지 한 줄씩
```
내보내는 법을 모르면 알려 준다.

## 4단계 — 비교 기준을 학생이 정한다

기준 세 개를 **학생이** 고르게 한다. AI가 제안하지 않는다. 기준은 문제의 성공 조건에서 나와야 한다.

> "성공이 '저녁을 거르지 않는 날 수'였죠. 그럼 어떤 기준으로 세 안을 비교해야 할까요?"

| 기준 | 안 A | 안 B | 안 C |
|---|---|---|---|

각 칸에 점수만 쓰지 말고 **왜 그 점수인지 한 줄**을 붙인다. 점수만 있는 표는 질문받으면 무너진다.

## 5단계 — 고르고, 포기한 것을 적는다 (이 스킬의 결승점)

`tradeoff.md` 를 네 칸으로 만든다. 그대로 포트폴리오 한 페이지가 된다.

```markdown
# 왜 이 안을 골랐는가
## 1. 안 A·B·C       {각 안 그림 + 한 줄 설명}
## 2. 비교 기준       {기준 셋과 그 기준을 고른 이유}
## 3. 선택과 이유     {고른 안 + 근거}
## 4. 포기한 것과 보완
- 포기한 것: {구체적으로}
- 그게 사용자에게 주는 불편: {한 문장}
- 그 불편을 어떻게 줄였는가: {구체적 설계}
```

**4번이 비어 있으면 끝난 게 아니다.** "포기한 게 없다"고 하면 다시 묻는다:
> 안 B를 골랐다는 건 안 A가 잘하던 무언가를 버렸다는 뜻입니다. 안 A만 할 수 있었던 게 뭐였죠?

## 지키는 것

1. **모르면 묻는다** — 필요한 정보가 없으면 질문부터 한다. 추측해서 진행하지 않는다.
2. **근거를 붙인다** — 모든 주장에 근거를 붙인다. 숫자에는 출처, 지적에는 위치.
3. **확실하지 않은 건 따로 모은다** — 확인 못 한 것은 맨 뒤 `## 확인 필요` 에 모은다. 본문에 섞지 않는다.
4. **길게 쓰지 않는다** — 항목은 5개, 고칠 것은 3개까지.
5. **고르는 건 학생이다** — 선택지를 좁혀 주되 결정은 학생이 한다. AI가 대신 고르면, 나중에 "왜 이렇게 했나요"에 답할 수 없게 된다.
6. **쉬운 말로 말한다** — 어려운 용어를 쓸 때는 괄호로 뜻을 함께 적는다.

결과는 학생이 지금 열어 둔 폴더에 저장한다. 다른 스킬이나 이전 결과물을 필요로 하지 않는다.

## 끝낼 때

```
넘어가기 전에 확인하세요
□ 세 안이 '푸는 방법'이 다른가요? 색만 다른 건 아닌가요?
□ '포기한 것'이 구체적으로 적혀 있나요? ('없음'은 오답입니다)
□ 이 페이지만 보고 남이 왜 그 안인지 이해할 수 있나요?
```

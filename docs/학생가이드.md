## 1. 이것만 치면 됩니다

```
/portfolio-design
```

그리고 **"화면 만들어줘"** 라고 하세요. 그게 다입니다.

### 준비가 덜 됐으면 AI가 먼저 알려 줍니다

바로 시작 못 하는 게 있으면 **그것만** 알려 줍니다. 준비가 다 됐으면 아무 말 없이 바로 시작합니다.

```
이 컴퓨터에 화면을 그리는 도구가 없어요.
없어도 오늘 수업은 됩니다. 그림 대신 글과 손그림으로 잡고,
계획은 그대로 남아요. 나중에 그림만 다시 받으면 됩니다.

  ○ 그냥 진행할게요  (추천)
  ○ 깔고 올게요
```

**시켜야 할 게 생기면 하고 나서 "완료" 라고 하세요.**
AI가 **다시 확인하고** 시작합니다. 안 됐으면 다른 방법을 알려 줍니다.

> 💡 수업 시간에는 **`그냥 진행할게요`** 를 고르는 게 낫습니다.
> 설치하다 보면 45분이 다 갑니다. 집에서 깔고 그림만 다시 받으면 됩니다.

## 2. 보기가 뜹니다. **누르기만 하면 됩니다**

AI가 몇 가지를 물어봅니다. **눌러서 고르는 화면**이 이렇게 뜹니다.

```
그 사람이 이걸 쓰는 순간은 어느 쪽에 가까울까요?

  ○ 퇴근길 지하철  (추천)
      한 손, 서서, 30초. 한 손으로 닿는 자리에 버튼이 옵니다

  ○ 집 소파
      두 손, 여유 있게. 정보를 더 많이 보여 줄 수 있습니다

  ○ 일하다 잠깐
      소리 못 켬. 조용하고 눈에 안 띄는 화면이 됩니다

  ○ 잘 모르겠어요 — 정해 주세요
```

**타자를 칠 필요가 없습니다.** 마음에 드는 걸 누르면 됩니다.

작은 글씨는 **"이걸 고르면 화면이 어떻게 되는지"** 입니다. 그걸 보고 고르세요.

### 모르겠으면 `잘 모르겠어요` 를 누르세요

막히지 않습니다. AI가 하나 정하고, **왜 정했는지 알려 줍니다.**
나중에 바꿀 수 있습니다. 여기서 멈춰 서 있는 게 제일 손해입니다.

### 보기에 내 답이 없으면

맨 아래에 **직접 쓰는 칸**이 항상 붙어 있습니다. 거기에 쓰면 됩니다.
"20대 직장인이요" 처럼 애매하게 써도 틀렸다고 하지 않습니다. 보기를 다시 만들어 줍니다.

## 3. 나오는 것

**링크 하나**가 나옵니다. 열면 큰 판에 화면 9장이 깔려 있습니다.

```
윗줄     = 안 A     [1장] [2장] [3장]
가운뎃줄 = 안 B     [1장] [2장] [3장]
아랫줄   = 안 C     [1장] [2장] [3장]
```

가로 한 줄이 **하나의 안**입니다. 세 줄은 **푸는 방법이 서로 다릅니다.**
트랙패드로 밀면 이동, 두 손가락으로 오므리면 확대됩니다.

> 링크는 AI가 알아서 적어 둡니다. 여러분이 저장할 필요 없습니다.

---

## 4. 여기서부터가 진짜입니다 — **고치기**

### 왜 고쳐야 하나요

채점표에 이렇게 되어 있습니다.

> **AI가 만든 것을 설명하지 못하면 −3점**

AI를 쓴 게 감점이 아닙니다. **"왜 이렇게 했어요?"에 답을 못 하는 게** 감점입니다.
답할 수 있게 되는 방법은 하나뿐입니다. **직접 고쳐 보는 것.**

### 뭘 고칠지는 AI가 먼저 알려 줍니다

여러분이 찾아낼 필요 없습니다. 이렇게 알려 줍니다.

```
세 개를 계획이랑 맞춰 봤어요.

  - 안 A — 배달 시간이 안 보여요
  - 안 B — 버튼이 한 손으로 닿기 어려워요
  - 안 C — 다 있어요

뭐부터 고칠까요?

  ○ 안 A에 배달 시간 넣기  (추천)
  ○ 안 B 버튼 내리기
  ○ 제가 다른 게 걸려요
```

**여기서도 누르기만 하면 됩니다.**

### 여러분이 직접 말해야 하는 건 딱 하나입니다

`제가 다른 게 걸려요` 를 고를 때입니다.
이때 **"좀 더 깔끔하게"** 같은 말은 안 통합니다. AI가 자기 마음대로 바꿔 버립니다.

**본 것을 말하세요.** 느낌 말고, 눈에 보인 것.

| ❌ 이렇게 말하면 | ⭕ 이렇게 말하세요 |
|---|---|
| "답답해요" | "**밀어 내려야 버튼이 보여요**" |
| "깔끔하게" | "**네모 칸이 8개라** 뭘 먼저 볼지 모르겠어요" |
| "세련되게" | "**글자 크기가 4가지라** 제목인지 설명인지 헷갈려요" |
| "글씨가 작아요" | "**지하철에서 안 보일 만큼** 작아요" |

> 💡 **"내가 뭘 보고 그렇게 느꼈지?"** 를 먼저 생각해 보세요.
> 그것만 말하면 나머지는 AI가 알아서 문장으로 만들어 줍니다.

### 한 번에 하나만 고칩니다

두 개를 같이 바꾸면 **뭐가 좋아진 건지 알 수 없습니다.**
고칠 게 여러 개면 제일 크게 걸리는 것부터 하나씩.

### 최소 두 번은 고칩니다

한 번 고치고 끝내지 마세요. 두 바퀴는 돌아야 "내가 만든 것"이 됩니다.

## 5. 발표할 때 읽을 문장이 쌓입니다

고칠 때마다 AI가 이런 걸 보여 줍니다.

```
기록장에 이렇게 적어 뒀어요.

  3/14 B안 첫 화면
  AI가 준 것   : 칸 8개를 쭉 나열
  내가 바꾼 것 : 3개만 남기고 나머지는 '더 보기'로
  왜           : 퇴근길에 30초 안에 골라야 해서

'왜' 부분이 맞나요?
```

**"왜" 부분을 꼭 확인하세요.** 이게 나중에 이렇게 쓰입니다.

- 발표할 때 **읽을 대본**
- 면접에서 "왜 이렇게 했어요?" 의 **답**
- 포트폴리오 마지막 회고 페이지의 **재료**

여러분이 파일을 열거나 저장할 일은 없습니다. AI가 다 합니다.

## 6. 문제가 생겼을 때

| 이런 일이 생기면 | 이렇게 하세요 |
|---|---|
| 명령어가 안 뜬다 | 앱을 껐다 켜세요. 그래도 안 되면 0번 설치를 다시 |
| "바탕화면이 열려 있다"고 한다 | `portfolio-2026` 폴더를 열고 다시 치세요 |
| 지난주 것이 안 보인다 | 폴더를 잘못 열었습니다. 늘 같은 폴더를 여세요 |
| 질문이 뭔 소린지 모르겠다 | **`잘 모르겠어요`** 를 누르세요. 알아서 정해 줍니다 |
| 보기에 내 답이 없다 | 맨 아래 **직접 쓰는 칸**에 쓰면 됩니다 |
| 세 개가 다 비슷하다 | **"세 개가 너무 비슷해요"** 라고 하세요 |
| 세 개의 색과 글꼴이 다르다 | **"글꼴이랑 색을 셋 다 똑같이 맞춰 주세요"** |
| 한 군데 고쳤는데 다른 데가 바뀌었다 | ⌘Z 로 되돌리고, **"나머지는 그대로 두고"** 를 붙여서 다시 |
| "화면판을 만들 수 없다"고 나온다 | 컴퓨터에 도구가 없는 경우입니다. 그날은 글과 손그림으로 하면 됩니다 |
| AI가 없는 기능을 그려 넣었다 | **"○○는 빼주세요"** 라고 하세요 |

## 7. 기억할 건 세 가지뿐입니다

```
① 명령 치고 "화면 만들어줘"
② 보기가 뜨면 누르기. 모르면 '잘 모르겠어요'
③ 고칠 때는 느낌 말고 '본 것'을 말하기
```

③번만 여러분이 직접 말합니다. 나머지는 다 누르기만 하면 됩니다.
준비됐는지, 어디까지 했는지는 **AI가 알아서 확인합니다.**
